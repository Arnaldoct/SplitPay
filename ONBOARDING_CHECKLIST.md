# Quick Start: Onboarding Checklist

Use this when onboarding a restaurant in person.

---

## ☑️ Pre-Visit Prep

- [ ] Run `npm run onboard` for their restaurant
- [ ] Note their login URL
- [ ] Bring laptop/tablet for demo
- [ ] Test card: 4242 4242 4242 4242

---

## ☑️ At Restaurant (15 min)

### Setup (5 min)
- [ ] Send magic link to manager's email
- [ ] Login together
- [ ] Add 3-5 tables in dashboard
- [ ] Generate & download QR codes

### Demo (5 min)
- [ ] Create test check:
  - Select table
  - Add 2-3 items
  - Show totals
- [ ] Scan QR code with phone
- [ ] Complete test payment
- [ ] Show transaction in dashboard

### Training (5 min)
- [ ] Walk through check creation
- [ ] Show split methods on guest side
- [ ] Explain tip flow
- [ ] Show transaction history
- [ ] Answer questions

---

## ☑️ Post-Visit

- [ ] Send printed QR codes (if needed)
- [ ] Email support contact
- [ ] Schedule follow-up call (1 week)
- [ ] Add to pilot tracking sheet

---

## 🗣️ Key Talking Points

**"This saves you ~10 minutes per table."**
- No more waiting for server to process cards
- Guests pay directly from their phones
- You see transactions instantly

**"It's like Venmo for restaurants."**
- Guests already comfortable with this flow
- No app download needed
- Works on any phone

**"You're in control."**
- You enter checks manually
- No POS integration needed (for now)
- Easy to issue refunds

**"We handle the payment processing."**
- PCI compliant (Stripe)
- Automatic receipts
- Funds hit your account in 2 days

---

## 🎯 Success Criteria

After visit, restaurant should be able to:
- [ ] Login to dashboard
- [ ] Create a check
- [ ] Generate QR code
- [ ] Process a test payment
- [ ] View transactions

---

## 🚨 Common Issues

**"I didn't get the magic link email"**
→ Check spam, resend from dashboard

**"QR code doesn't work"**
→ Regenerate, make sure dev server is running

**"Payment failed"**
→ Use test card 4242..., check Stripe keys

**"How do I edit a check?"**
→ Void and recreate (edit coming soon)
